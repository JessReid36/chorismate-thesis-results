WHAT WAS FOUND
On 20 October 2026 Jessica viewed the development grid with the development A matrix (exploratory/dev_A/, results
6edfbb1), showing negative spheres only. Beside H8 a second, farther-out set of positions appeared. These are the 277
cation-layer sites beside H8:
  - they sit 3.68 A from H8, the closest a positive sphere may come there (floors.tsv);
  - they lie outside the anion/neutral layer, which reaches 2.52 A from H8 on this grid;
  - so they clear the q <= 0 floors, and section 4's rule ("Each site admits every charge whose floors it clears at
    every geometry: q in [-1, 0] if it clears the q <= 0 floors") admitted q in [-1, 0] there.
Everywhere else, negative and neutral spheres have positions only at Lennard-Jones contact, on the anion/neutral layer.
Only beside H8 did they also get a second set, farther out, built for positive spheres. Jessica's question (20 October
2026): "we are working with -1 spheres not +1 in this instance so why are we placing spheres on a layer that is not
designed for them?" Her decision, the same day, between this amendment and handling it only in the optimiser's null
distribution: "lets go with option 1".

What those positions do, measured on the development set (first order, frozen geometry; exploratory):
  - a -1 sphere at any of the 277 sites raises the barrier: mean over the 30 frames +0.79 to +3.39 kcal/mol, and
    raised in every frame at 238 of them;
  - a neutral sphere there acts only through L: mean -0.04 to +0.01 kcal/mol.
So the optimiser would not choose them for a negative sphere. They would, however, bias the null distribution (the
optimiser stage's random arrangements). Random negative spheres drawn from them only raise the barrier, which makes
random designs worse and optimised designs look better by comparison.

CHANGE
- Section 4: "q in [-1, 0] if it clears the q <= 0 floors" becomes "q in [-1, 0] if it is an anion/neutral-layer site
  and clears the q <= 0 floors; cation-layer sites admit positive charges only".
- Section 3: "some sites admit two separate ranges, e.g. q in [-1, 0] and [0.5, +1]" stays true for the 50
  anion/neutral-layer sites that admit [-1, 0] and a positive range from 0.50, 0.75 or 1.00. The 277 cation-layer sites
  beside H8 now admit +1 only.
- cs5_grid.py:
  - admitted() takes each site's layer and admits q <= 0 on the anion/neutral layer only;
  - grid and check both use it;
  - the sites file's header states the rule;
  - the module's description says why.
  Nothing else changes. The cation layer's drop rule depends only on a site's clearance to the q <= 0 floors and on its
  positive charges, so the same sites are kept, at the same positions, in the same order. Floors, L and the A-matrix
  rows are unchanged.
